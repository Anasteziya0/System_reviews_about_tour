# Система отзывов об экскурсиях

## Назначение

Приложение предназначено для сбора, хранения и просмотра отзывов об экскурсиях.
Консольная версия приложения (ПР3) дополнена веб-интерфейсом на Django (ПР5).

Приложение позволяет:
* просматривать экскурсии в браузере;
* просматривать информацию о конкретной экскурсии и её средний рейтинг;
* просматривать список отзывов в браузере;
* просматривать информацию о конкретном отзыве;
* находить экскурсии по названию (консольная версия);
* сортировать экскурсии по цене и отбирать их по максимальной цене (консольная версия);
* добавлять отзывы с проверкой оценки от 1 до 5 (консольная версия);
* считать статистику отзывов (консольная версия);
* управлять пользователями (консольная версия);
* хранить данные между запусками приложения.

## Используемые технологии

* Python 3;
* Django 5.2 – веб-фреймворк;
* HTML – разметка веб-страниц;
* CSS и Bootstrap 5.3 – оформление страниц;
* pytest – автоматизированные тесты;
* flake8 – проверка качества кода.

## Целевая аудитория

* туристы и посетители экскурсий, желающие оставить отзыв и ознакомиться с отзывами других;
* организаторы и экскурсоводы, заинтересованные в обратной связи и рейтинге своих экскурсий.

## Предметная область

Основными объектами предметной области являются:
* экскурсия;
* пользователь;
* отзыв.

Пользователь оставляет отзыв об экскурсии: оценку от 1 до 5 и комментарий.
Оценка вне диапазона от 1 до 5 не принимается.
Оценка 4–5 считается положительной, 3 – нейтральной, 1–2 – отрицательной.
Средний рейтинг экскурсии считается по всем её отзывам.

## Основные сущности

### Tour – экскурсия

Объект `Tour` представляет экскурсию, о которой оставляют отзывы.

Основные атрибуты:
* `id` – уникальный идентификатор экскурсии;
* `name` – название;
* `place` – место проведения;
* `price` – цена;
* `duration` – длительность в часах.

Основные методы:
* `is_within_budget()` – проверка, что цена не превышает заданную;
* `__str__()` – строковое представление экскурсии.

### User – пользователь

Объект `User` представляет пользователя системы.

Основные атрибуты:
* `id` – уникальный идентификатор пользователя;
* `name` – имя пользователя;
* `email` – адрес электронной почты.

Основные методы:
* `__str__()` – строковое представление пользователя;
* `from_data()` – создание объекта `User` из набора данных.

### Review – отзыв

Объект `Review` представляет отзыв пользователя об экскурсии.

Основные атрибуты:
* `id` – уникальный идентификатор отзыва;
* `tour` – объект `Tour`;
* `user` – объект `User`;
* `rating` – оценка от 1 до 5;
* `comment` – текст комментария;
* `review_date` – дата отзыва.

Основные методы:
* `validate_rating()` – проверка оценки на диапазон 1–5 (`@staticmethod`);
* `get_status()` – статус отзыва по оценке;
* `__str__()` – строковое представление отзыва.

## Страницы веб-интерфейса

* `/` – главная страница: описание приложения и навигация (view-функция `index()`);
* `/tours/` – список экскурсий: объекты `Tour` из `data/tours.json` (view-функция `tours()`);
* `/tours/<int:tour_id>/` – страница экскурсии (view-функция `tour_detail()`);
* `/reviews/` – список отзывов: объекты `Review` из `data/reviews.json` (view-функция `reviews()`);
* `/reviews/<int:review_id>/` – страница отзыва (view-функция `review_detail()`).

Если экскурсия или отзыв с указанным идентификатором не найдены, соответствующая страница возвращает код статуса 404.
Для несуществующих адресов подключён собственный обработчик 404 (`handler404` – `page_not_found()`).

## Основные операции

### Используется в веб-интерфейсе (ПР5)

* просмотр списка экскурсий;
* просмотр информации об экскурсии;
* просмотр среднего рейтинга экскурсии;
* просмотр списка отзывов;
* просмотр информации об отзыве.

### Отложено до следующих работ

Эти операции реализованы в ПР3 и работают в консольной версии. В веб-интерфейсе они появятся, когда будут добавлены формы и POST-запросы:

* добавление экскурсии;
* поиск экскурсии по названию;
* сортировка экскурсий по цене;
* отбор экскурсий по цене;
* добавление отзыва;
* статистика отзывов;
* создание пользователя;
* поиск пользователя.

## Хранение данных

Данные приложения хранятся в JSON-файлах:
* `data/tours.json`;
* `data/users.json`;
* `data/reviews.json`.

При загрузке данные из JSON преобразуются в объекты `Tour`, `User` и `Review`.
При сохранении объекты преобразуются в данные JSON.

Для связи отзыва с экскурсией и пользователем в `reviews.json` используются их идентификаторы `tour_id` и `user_id`.

## Назначение модулей

### `main.py`

Консольная версия приложения (сохранена с ПР3).
Отвечает за:
* запуск консольного приложения;
* отображение меню;
* получение данных от пользователя;
* организацию пользовательских сценариев.

### `tourreviews/`

Пакет настроек Django-проекта:
* `settings.py` – настройки проекта;
* `urls.py` – маршрутизация верхнего уровня;
* `asgi.py`, `wsgi.py` – точки взаимодействия с сервером.

### `homepage/`

Django-приложение, отвечающее за главную страницу:
* `views.py` – функция `page()` (общий HTML-каркас), функция `rating_badge()`, view-функция `index()` и обработчик `page_not_found()`;
* `urls.py` – маршрут главной страницы.

Функция `page()` размещена здесь, потому что главная страница задаёт общий вид всех остальных страниц – она точка входа в проект. Остальные приложения импортируют её.

### `tours/`

Django-приложение, отвечающее за экскурсии:
* `views.py` – view-функции `tours()` и `tour_detail()`;
* `urls.py` – маршруты приложения;
* `models.py` – Django-модели (заполняется в следующих работах).

### `reviews/`

Django-приложение, отвечающее за отзывы:
* `views.py` – view-функции `reviews()` и `review_detail()`;
* `urls.py` – маршруты приложения;
* `models.py` – Django-модели (заполняется в следующих работах).

Приложение для пользователей не создаётся: Django предоставляет встроенную модель `User` (`django.contrib.auth`).
Модуль `models/users.py` остаётся частью консольного приложения.

### `models/`

Классы предметной области и функции работы с ними (пакет ПР3):
* `tours.py` – класс `Tour` и функции работы с экскурсиями;
* `users.py` – класс `User` и функции работы с пользователями;
* `reviews.py` – класс `Review` и функции работы с отзывами.

### `storage.py`

Отвечает за загрузку и сохранение данных.
Выполняет преобразование:
* JSON → объекты Python;
* объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции консольного ввода:
* `input_int()` – безопасный ввод целого числа;
* `input_float()` – безопасный ввод числа;
* `input_date()` – безопасный ввод даты;
* `input_text()` – ввод непустой строки.

### `tests/`

Содержит автоматизированные тесты проекта.
